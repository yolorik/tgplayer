## TGPlayer 2.6.0d

Встроена проверка обновлений.

### Что нового

- **Проверка обновлений при запуске.** Раз в запуск плеер спрашивает
  GitHub и, если вышла новая версия, предлагает обновиться. Проверка идёт
  в фоне и на запуск не влияет.
- **Скачивание и установка по кнопке.** Плеер скачивает установщик,
  сверяет контрольную сумму и — после подтверждения — закрывается,
  ставит новую версию и запускается снова.
- **Два канала обновлений.** «Только проверенные» и «Все сборки» —
  выбирается в настройках, блок «О программе».
- **Отложить версию.** Галочка «не предлагать эту версию снова»: если
  новая сборка окажется хуже, обратное предложение не будет мешать.

### Как установить

Скачать `TGPlayer_Setup.exe` из раздела Assets ниже и запустить.

Контрольная сумма — в `SHA256.txt`.

### Проверка целостности

```
certutil -hashfile TGPlayer_Setup.exe SHA256
```

Сверить с содержимым `SHA256.txt`.
